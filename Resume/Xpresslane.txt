Xpresslane:

Xpresslane is an app designed for online shopping websites that helps make the checkout and payment process faster and easier.
It’s mainly made for small e-commerce businesses so their customers can buy products quickly using features like 
personalized checkout, one-click payment, order tracking, refunds, and reorders — all in one place.

With Xpresslane, both buyers and business owners get a smooth experience:
Customers can complete purchases quickly, track deliveries, reorder items, or request refunds without hassle.
Businesses can improve their sales and customer satisfaction by offering a better, faster checkout system.

Websites can combat abandoned carts and experience a significant improvement in conversions by adding easy plugins. 
Xpresslane also provides a merchant dashboard where merchants can customize their payment mode discounts, payment mode charges, and shipping options.

SKU Configuration: SKU stands for Stock Keeping Unit.
Products are assigned different SKU numbers based on color, style, type and size. 
Customization of products involves selecting features such as color, design, add-ons to 
make a more unique item for that particular customer rather than a mass produced one.

The SKU details of the products of a particular merchant can be uploaded via a File Uploader through the interface. 
The template for the file upload can be downloaded before uploading that provides the merchants with the format of the file that could be uploaded through the interface. 
The SKU based charges are further broadly categorized into price based and weight based.

Every gift card has monetary value loaded in them and has an expiration time set by the merchant. 
Once the gift card is applied in the discount section in the checkout process, it is 
validated against the merchant’s store through the store's admin API. 
After the payment, if it is known that the gift card is reused, order placement will not happen and the respective merchant is notified through mail.

Hitting the gift card API for all checkout discounts irrespective of the merchants will increase the response time of the application of discounts, 
resulting in a huge impact on the fast checkout experience,  Higher latency More network load
Optimization: Flag in Admin Console, only flag set true, hit the api on checkout
Use a feature-flag to enable/disable gift card support per merchant dynamically.
This helps rollout gift cards gradually, avoid hitting upstream APIs for merchants not ready.





Capability for  cross-domain cookies for different merchant domains under Xpresslane. 
(Have to Redirect to name of merchant domain from xpresslane domain)
Local Storage is not generally shareable between different domains. 
But local storage can contain crucial information like authentication data that will be needed by other domain.
The data from local storage of one domain once set could  be sent to another domain using redirection and passing the data as URL params after being encoded.
Once redirected the data from the URL params is decoded and set in the local storage of redirected domain.
Then once again redirect back to the original domain after sharing the local storage data.

Parallel Chunk Uploads:
Faster upload time	Utilizes available network bandwidth efficiently
Lower retry cost	Only failed chunks retry, not whole file
Resumable Uploads Save completed chunk indexes in localStorage
User refreshes → continue where left off.

function createChunks(file, chunkSize = 5 * 1024 * 1024) {
  let chunks = [];
  let start = 0;

  while (start < file.size) {
    chunks.push(file.slice(start, start + chunkSize));
    start += chunkSize;
  }
  return chunks;
}
